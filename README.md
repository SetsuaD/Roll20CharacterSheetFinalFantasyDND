## Usage

1. Create a new campaign or open an existing one in Roll20.
2. Go to the Game Settings.
3. Under "Character Sheet Template", select "Custom".
4. Copy the contents of the HTML file into the HTML Layout tab.
5. Copy the contents of the CSS file into the CSS Styling tab.
6. Save your changes.

## Development

- **HTML:** Defines the structure and layout of the character sheet.
- **CSS:** Defines the styling, colors, and visual appearance of the character sheet.
